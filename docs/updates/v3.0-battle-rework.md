# v3.0 战斗系统重做:意图 × 能量 × 弱点节奏

> 用户决策(2026-10-17):"把战斗系统重做,现在的一点也不好玩,先调研好玩的战斗系统再回来改。"
> 方法:先调研(独立代理 10 次搜索 + 9 篇深读:RPS/GDC 对 Slay the Spire 主创的访谈、Into the Breach 确定性设计分析、Persona One More 机制分析、Smogon/The Vault 宝可梦预测理论、XCOM 随机性访谈等),基于调研的最小可行改造集落地。

## 为什么旧系统不好玩(重做前的诊断)

1. **招式同质化**:每只精灵 2-3 个招式全是纯伤害(撞击 40 + 属性招 65),选择退化成"点倍率最高的按钮"。
2. **无信息博弈**:AI 行动不可预测也无从反制,每回合排队换血。
3. **无节奏管理**:没有资源/冷却,每回合等价,最优解恒定 → dominant strategy。
4. **换人是伪决策**:AI 不针对换人做任何应对。
5. **AI 推演模式的理由只是风味文本**,不构成博弈。

## 调研结论 → 设计映射

调研产出 13 条带出处的原理,选定四件互相咬合的机制(信息→目标→取舍→对手的决策闭环):

| 原理(来源) | 落地机制 |
|:--|:--|
| 意图预告:把"猜黑盒"变成"解已知题"(Slay the Spire,RPS 访谈 Giovannetti) | **意图系统**:服务器在玩家行动前生成并下发 AI 本回合的承诺行动,UI 显示意图气泡 |
| 打弱点=知识兑换行动经济,双向对称(Persona One More) | **弱点回能**:命中克制(≥2x)攻击者 +20⚡;被打者痛感回能 +10⚡(双向) |
| 行动点经济:防御=储蓄、进攻=透支(Bravely Default / StS) | **能量系统**:招式分四档费用,防御指令回能+减伤,换人蓄势回能 |
| AI 混合策略+读心层级(Smogon/The Vault 预测理论) | **AI 从 top-3 评估动作按权重抽样**(0.62/0.28/0.10),意图可见但倾向可读 |
| 反 dominant strategy(5 Core Pillars) | 克制招更贵:迅(0)/强(25)/重(45)/极(90),无脑点克制会被能量卡住 |
| 即时反馈(Persona 5 分析) | 意图气泡、能量条、⚡回能弹字、招式按钮费用徽章 |
| 确定性结算(ItB)+ 概率情绪学(XCOM) | 无命中掷骰、无暴击,伤害浮动收紧(10%),随机性只留在 AI 抽样 |

明确**不做**(本轮 scope 外,记录在案):状态异常(灼烧/麻痹)、pivot 换人招(U-turn 类)、前后排站位、第二资源条(气势)——先让核心闭环立住,数据说话后再加。

## v3 规则卡

**招式四档**(每只精灵 4 招,由属性/种族值派生,零新数据依赖):

| 档位 | 威力 | 费用 | 先制度 | 说明 |
|:--|:--|:--|:--|:--|
| 迅招 | 40 | 0 | +1 | 免费、先手;能量紧张时的保底与斩杀抢跑 |
| 强招 | 65 | 25 | 0 | 与旧版属性招同威力(id 不变,连续性) |
| 重招 | 95 | 45 | 0 | 双属性用第二属性(覆盖面!),单属性同属性 |
| 极招 | 135 | 90 | 0 | 满能量爆发 |

**能量规则**(0-100,开局 25):
- 回合开始:在场 +15,替补 +5(热身)
- 防御指令:受伤减半(本回合)+ 回能 35 —— 蓄力是投资下回合
- 换人:换上的精灵 +10(动量)
- 被打:受伤回能 +10(痛感;挨打不是纯亏)
- 打中克制(≥2x):攻击者 +20(知识兑换节奏;AI 打你也一样)
- 能量不足时点贵招:服务端自动降档为迅招(与旧版"非法招式回退普招"同款容错)

**回合流程**:换人(先)→ 防御标记 → 招式按先制度/速度结算 → KO 自动补位 → 清除防御 → 生成下一回合 AI 意图。

**意图系统**:AI 行动在玩家行动**之前**就已掷定并持久化在 state(`aiIntent`),UI 如实展示——反制是真实的;AI 换人后旧意图失效则按规则重生成。AI 推演(reasoned)模式下由 LLM 选意图(带能量/意图语义的新提示词,失败回退混合策略)。

**AI 评估函数**(混合策略):招式分=期望伤害×KO 加成;防御分=残血权重+高能量蓄势;换人分=克制关系差。top-3 加权抽样。

## 工程决策

- **双引擎并存**:`resolveTurn`(旧,语义不变)保留给好友 PvP 模拟器与存量 active 战斗;新 PvE 一律 `version: 3` 走 `resolveBattleTurn`。好友系统零波及。
- `battleMonFromCard(card, { v3 })`:默认旧招式(好友/存量),v3 显式开启——同一函数两代招式派生。
- 服务器权威/乐观锁/事件回放管线/编队/战绩全部复用;state JSONB 加字段,无 DDL。
- 意图在 /turn 响应后生成并随 state 下发,无额外往返。

## 验证计划

- 引擎单测 v3 新段(能量扣费/先手/防御减半/弱点回能/降档/意图确定性)+ 旧 17 断言不动。
- e2e 对战段补充 v3 字段与 guard 行为断言(原段本来就是从 state 读招式 id,天然兼容)。
- 浏览器实测:意图气泡、能量条、防御按钮、回能弹字、移动端 390px。
