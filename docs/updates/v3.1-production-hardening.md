# v3.1 生产级加固(商业级差距整改)

> 用户决策(2026-10-17):"做全量的调研和修改,我认为我的网站还到不了商业级别的项目。"
> 方法:三路并行调研/审计(生产级标准调研 15 项带出处 + 服务端逐行审计 + 前端逐行审计),
> 汇总成差距清单后按"资损/安全 → 可靠性 → 死路修复 → 中国可用性 → 工程流程/信任"落地。
> 明确不做清单(k8s/多区域/企业反作弊 SaaS/Sentry 双栈等)见调研报告,防过度工程。

## 已落地(29 项)

### 资损与安全(P0)
1. **DB TLS 证书校验**:`rejectUnauthorized: false → true`(此前等于"加密但不认证",连接可被中间人,拿到 DATABASE_URL 密码并解密全部流量——含 session id 与钱包数据)。Neon 公共 CA,系统根证书可验;本地 Docker 保持关。
2. **PvE 战斗奖励 24h 滚动上限(10 场)+ start/turn 限流(30/10min、60/10min,用户维度)**:此前脚本循环 start→win 每场 100 币无限刷——全站最大经济水龙头,把 daily bonus 和 PvP 防刷全部架空。结算依据直接用 wallet_tx 账本(kind='battle'),与 PvP 的 rewardable() 同口径。
3. **并发 start 双开战斗**:battles 表加部分唯一索引 `uq_battles_active_user (user_id) WHERE status='active'` + 插入撞 23505 回落复用——把竞态焊死在数据库层而非应用层 check-then-insert。
4. **CSRF 纵深(Origin 校验)**:非 GET /api 的 Origin/Referer **在场时**必须与 Host 同源(浏览器一定带 → 拦截跨站伪造;curl/测试无 Origin → 放行不破坏脚本)。与 SameSite=Lax 组合后达到商业标准,不需要完整 token 机制。实测:跨站 POST 403、无 Origin 正常 401。
5. **CSP + HSTS**:严格 CSP(script-src 'self';style 'unsafe-inline' 是 React 内联样式的公认取舍;connect-src 保留 Datadog RUM 上报口)+ HSTS 一年。SPA 静态托管的正确形态——nonce/strict-dynamic 需要逐请求注入,本架构做不到,明确不走。浏览器实测零违规、全站正常渲染。
6. **静态资源 immutable 缓存**:vercel.json `/assets/*` → `public, max-age=31536000, immutable`;本地 Express 同款 setHeaders;index.html 不缓存(新版本立即生效)。

### 可靠性(P1)
7. **池死锁修复**:pool 加 `connectionTimeoutMillis: 5000` + `statement_timeout: 5000`;**事务内经 q() 再取池连接的全部调用点改走事务 client**(friends 的 areFriends/friendCount/inBattleTeam/assertOwnedCards/usernameOf + gacha 十连的 loadCardById)——满池时互相等待 = 全池悬挂到函数超时强杀。
8. **外呼超时补齐**:lore 事实抓取 10s、LLM 流式/非流式 45s(与客户端断开 signal 求并)、Datadog 推送 10s——上游半死不活时不允许拖着函数烧钱。
9. **保底并发竞态**:forceRarity 判定移入 lockPity 之后用锁内计数重判——并发单抽都读到阈值前旧值时,此前会双双强制 UR。
10. **健康检查语义**:db 异常 → 503(此前恒 200 ok:true,拨测等于失明);浅检查不碰重启语义。
11. **SPA fallback 跳过 /api**:未知 /api 路径返回 404 JSON 而非 200 HTML(排障困惑 + 测试假绿温床)。
12. **好友申请 outgoing 上限(10)+ 自己好友数前置检查**:补齐 trades/challenges 早有的 cap 纪律,堵陌生人 inbox 轰炸。
13. **friends 列表三查询并行**(Promise.all)。

### 前端死路与体验(P0/P1)
14. **对战回合失败 UI 永久锁死**:postAction 失败路径现在也复位 playing(此前连"重试"按钮都被 playing 禁用,唯一出路是刷新)。
15. **对战页初始加载失败 = 永久"加载中…"**:新增失败态 + 重试按钮(此前 error 只在成功分支渲染)。
16. **startBattle/saveTeamFromEditor 补 catch**:网络错/HTML 响应此前是 unhandled rejection,用户零反馈。
17. **Google Fonts @import 移除 → 系统字体栈**:fonts.googleapis.com 在大陆被墙且是 CSS 串行阻塞链,首屏挂到超时。CJK 站点用 PingFang/雅黑栈是工业界选择。
18. **datadog chunk 不再被 modulepreload 进首屏**(238KB):`modulePreload.resolveDependencies` 过滤——拆 chunk 只是不执行,preload 照样抢首屏带宽。
19. **根级 ErrorBoundary**:Header/ChatPanel 在视图边界外,它们 render 崩 = 整站白屏;根边界保"还能刷新"。
20. **api-unauthorized 广播终于有接收端**:会话过期统一 toast + 引导重登(此前的承诺注释是死代码)。
21. **WikiView**:param encodeURIComponent + 物种请求走代理 + 内层失败 setError(此前静默 = 永久 loading)。
22. **logout 补 catch**(点了退出却保持登录态且无提示)。
23. **ErrorState 中文化**(此前英文 "Oops, capture failed" 且直渲染原始 error)。
24. **浅色主题 text-dim 对比度 2.3:1 → AA 达标**(≥4.5:1)。
25. **viewport-fit=cover**(iOS 安全区真实生效)+ **preconnect jsdelivr**(首屏立绘域预热)。
26. **Splash**:同会话只出现一次(sessionStorage)+ 不再劫持深链(#/battle 刷新留在原页,与既有 QA 教训一致)。

### 中国可用性(商业站分水岭)
27. **PokeAPI 服务端代理 `/api/poke/*`**:路径白名单(pokemon/pokemon-species)+ 进程内 24h 缓存(1500 条 LRU-ish)+ 下发 Cache-Control + 10s 外呼预算。第三方数据源收进自己可控边界——此前只镜像了图,数据仍直连 pokeapi.co(国内不稳),图鉴/词条/今日精选弱网下骨架屏到永远。前端 POKEAPI_BASE 全部切换,species.url 取 id 走代理。

### 工程流程与信任
28. **GitHub Actions CI**:push/PR 自动跑 typecheck + build + seed + **postgres:16 service container 上的五套件**(164 断言);无 GLM key 时自动 mock 模式,CI 不依赖任何密钥。
29. **隐私政策 + 服务条款页**(#/privacy #/terms,登录页注册模式挂链接):如实披露"日志含 IP、对战内容发给智谱 GLM 处理、图鉴币无真实价值、AI 生成内容免责"——GDPR Article 13 的最低合规 + 商业信任信号。
30. **request-id 轻量中间件**:透传/生成短 id,echo 回响应头,wrap() 的服务端日志带上——一条失败请求的日志可以串起来(不上 pino,Vercel 侧已有日志收集)。
