## 五阶段实施

### 阶段 0 安全网(dcd6ef3)
新增 qa/v23-e2e.mjs(24 断言):十连完整语义(缺口扣费精确/重放不扣费/子键幂等/满额精确)、pity 端点形状、logout 会话销毁。**首版断言修正**:缺口订单重放的真实契约是"重放已成功的子键 + 再现缺口",不会凭空补足 10 张——修断言以钉死真实行为。

### 阶段 1 共享内核(b40235a)
- `http.ts`:HttpError(status, message, code) / wrap(domain, internalMessage, fn) / requireUser(一次归一 BIGSERIAL→Number) / bad() / clientIp()
- 错误契约:`{ error: 机器码, message: 中文 }`;4xx 带 code(gacha_failed/invalid_username/...),5xx 用域内友好文案;HttpError(500) 保留自定义文案
- `wallet.ts` addWalletTx:唯一 ledger 写点(5→1)
- `cards.ts` loadCardsByIds/loadCardById:唯一卡片投影(4→1)
- `battle.ts` chooseAction(state, side):规则脑对称化,删模拟器拷贝;chooseAiAction 保留为兼容别名
- lore.ts 迁入内核

### 阶段 2 安全加固(9f552ce,零新依赖)
- 安全响应头 ×4(XCTO/XFO/Referrer-Policy/Permissions-Policy);CSP 暂缓(需配合产物名单独调)
- clientIp:XFF 最右条目(Vercel 边缘追加,唯一可信;最左可被客户端注入)
- `ratelimit.ts`:rate_events 表 + 滚动窗口 + 单语句 CTE(采样清理/记账/计数一次往返);挂 chat 20/24h、register 10/24h、lore 100/24h(缓存未命中才计)、login 10/15min;RATE_LIMIT_SCALE 本地放大;DB 错误 fail-open
- scryptSync → promisified async;createSession 清扫本用户过期会话 + 5% 全表采样
- admin/seed 500 不回 err.message;ensureSchema 升全局 /api 门(修好友/对战/lore 表冷启动首打 500)

### 阶段 3 性能(a44ac7c)
- tenpull 单事务(往返 10→1):drawCore 从 free/charged 两份拷贝提取,十连在单事务内循环子键;语义由 v23 套件钉死
- /api/friends 三查询 Promise.all;LIMIT 补齐(收藏 500/pending 50/trades 200/卡池 200);catalogNames 60s TTL 缓存

### 阶段 4 前端小修(0bf2aca)
- `src/api/client.js`:统一 /api 封装(JSON 解析/错误提取/401 广播/soft 选项);迁移最痛三处(PacksView pity ×3、FriendsView call、BattleView 十连格),其余 40 处渐进
- 常量收敛 config/pokemon.js:RARITY_SHORT/LONG/DOT/RANK/CHIP_CLS(4→1)、statColor(2→1)、WikiView statLabels→STAT_LABELS_ZH
- PacksView/BattleView CDN 硬编码 → artworkUrl;DexView 归位 views/;splash.css 双重导入去除
- vite manualChunks:node_modules → vendor.js,**主包 236KB → 19KB**(vendor 222KB 长缓存)

## 过程抓到的 bug(每一轮都有)

1. **限流倍率 dotenv 时序**(QA-039):SCALE 在模块导入时求值,先于 createApp() 的 loadEnvFile → .env.local 永远读不到,本地套件 429。改惰性读取。教训:**模块顶层读 env 必须保证注入先于导入**。
2. v23-e2e 对缺口重放语义的预设错误 → 修断言钉死真实契约(重放 7 张+缺口 3)。
3. client.js 复发".js 内 TS 参数属性"文档坑(esbuild 静默解析失败)→ 显式赋值。
