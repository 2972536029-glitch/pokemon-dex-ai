# v2.5 观测展示面迁移 Datadog(RUM + 每日指标推送)

> 用户决策(2026-10-17):"看板放 Datadog 上,别放站里"。
> 架构调整:自建管线收窄为**业务数据源**(CSAT 评语落库、行为埋点聚合),性能/错误/会话明细归 **Datadog RUM**,业务 KPI 由 **Vercel Cron 每日推送** Datadog HTTP API;站内 `#/metrics` 看板删除。
> 组织:公司 org `us5.datadoghq.com`(与 skin-shop 同源,观测叙事统一)。

## 职责切分(v2.4 → v2.5)

| 信号 | v2.4(全自建) | v2.5 |
|:--|:--|:--|
| Web Vitals / JS 错误 / 视图 | telemetry_events + 站内看板 | **Datadog RUM SDK**(独立异步 chunk,env 门控) |
| 行为埋点(抽卡/对战/问答) | 自建 | **双轨**:RUM `addAction`(会话上下文)+ 自建(每日 KPI 数据源) |
| CSAT 满意度 | feedback 表 + 站内看板 | feedback 表持久化(评语必须落库)+ cron 推均分/条数 + `addAction("csat")` |
| API 服务端计时 | 自建 | 自建采集 + cron 推 p95 / 错误率 |
| 展示面 | `#/metrics` 站内页(**已删**) | Datadog Metrics / RUM 界面 |

## 每日指标推送

- `GET /api/metrics/flush`(vercel.json cron,每日 UTC 3:00 = 北京 11:00):
  - 鉴权:Vercel Cron 自动带 `Authorization: Bearer $CRON_SECRET`;手工运维走 `x-seed-key`(与 /api/admin/seed 同款钥匙,零新密钥概念)。
  - 窗口:24h 滚动(延续 QA-037 纪律,不做本地时区「切天」)。
  - 指标族 `pokemon.*`:`dau`、`api.requests`、`api.errors`、`api.p95_ms`、`feedback.count`、`feedback.avg_score`、`usage.<action>`(逐动作计数),打 `service:pokemon-dex-ai, env:prod` 标签。
  - 推送:POST `https://$DD_SITE/api/v1/series`(serverless 无 agent,HTTP API 是唯一口子);DD_API_KEY 缺失时降级为只返回聚合(本地可验证),失败原因进日志不进响应。

## RUM 接入与降级

- `@datadog/browser-rum` v7,动态 import 独立异步 chunk(主包 21.2KB 不变);`VITE_DD_CLIENT_TOKEN` / `VITE_DD_APPLICATION_ID` 缺任一 → **自建管线全量兜底**(本地开发零配置,行为同 v2.4)。
- RUM 接管后,自建的 webvital / jserror / pageview 停发(避免双份);usage 双轨(addAction + 自建)。
- sessionReplaySampleRate = 0(游戏站不需要回放,省会话配额);sessionSampleRate 可用 `VITE_DD_SESSION_SAMPLE_RATE` 调节(默认 100)。

## 删除与保留

- 删除:`MetricsView.jsx`、`#/metrics` 路由与导航入口、`/api/metrics/overview`、`requireAdmin` 守卫、auth 层 is_admin 代码路径、`mtr-*` 样式块。
- 保留:schema 的 `users.is_admin` 列(运维保留位,DDL 注释已说明)、`/api/telemetry`、`/api/feedback`、API 计时中间件、45 天保留期清理。

## 密钥纪律

`DD_API_KEY` / `CRON_SECRET` 只进 Vercel Secrets(`vercel env add` 管道直读本地课程密钥文件,无回显、无落盘);仓库与代码保持零密钥,`DD_SITE` 等非敏感项走环境变量。

## 验证

- `qa/telemetry-e2e.mjs` 改版 23 断言:采集/校验/反馈 upsert 不变;看板段替换为 flush 鉴权三态(无钥匙 403 / 错 Bearer 403 / 钥匙 200)+ 指标齐全性 + dd 缺 key 降级路径。
- 五套件 143 断言绿(e2e 36 + friends 43 + v23 24 + engine 17 + telemetry 23)。
- 过程坑(两次撞上 SPA fallback 假绿):本地 server 未用 watch 模式,改代码后旧进程仍在服务,未知端点被包成 200 HTML——这正是套件里「先 text 后 JSON」防线存在的理由;另修复套件脚手架 `req()` 不认 `headers` 参数导致钥匙从未发出。
- Datadog 侧验证(Metrics Explorer 查 `pokemon.*`、RUM 会话)在 RUM 应用创建并部署后进行。
