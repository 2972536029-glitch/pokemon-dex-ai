# v2.1 开包仪式 v3 —— 十连的仪式感 + 全量精致化

> 背景:用户反馈「抽卡动画能不能更精致一些,包括十连为什么没有单抽的仪式感」。
> v2.0 现状:单抽有完整四幕仪式(摇晃→点击撕开→炸开→暗场汇聚→揭示);十连却直接弹九宫格,没有包装、没有悬念。

## 设计:十连复用同一套撕包仪式,加"卡背阵列 + 压轴揭示"

参考商业抽卡(Arknights 连抽 / 原神跃迁)的公共节奏:**包装仪式 → 爆开 → 面板朝下 → 按稀有度升序逐张翻开 → 最高稀有度压轴爆发**。

### 十连流程(新)

| 幕 | 阶段 | 内容 |
|:--|:--|:--|
| 1 | pack | 大包摇晃 1.3s → 停在"点击拆开"(与单抽同款,等待玩家) |
| 2 | burst | 白闪 + 冲击波 + 两半飞散 + 粒子(颜色按本包最高稀有度染色) |
| 3 | ten-reveal | 5×2 卡背阵列落地(精灵球卡背),按 C→R→UR 逐张自动翻开:C/R 快节奏 380/500ms,UR 前 1s 心跳停顿 |
| 4 | 压轴 | 翻到 UR:全屏金光闪 + 边缘脉冲 + 卡位金环扩散;未翻完可点任意处加速 / 「全部翻开」;「跳过动画」直接翻完 |

### 单抽精致化

- 炸开粒子此前固定金/白,现在吃稀有度染色变量(`--ark-glow/--ark-core`):C 蓝白 / R 亮青 / UR 金——撕开瞬间就有"金光=UR"的悬念信号
- `ark-r-*` 染色从 converge 提前到 burst 生效(pack 摇晃段保持中性,不剧透)

### 实现要点

- `stage` 复用:`pack → burst` 与单抽共享;`tenMode` 标志决定 burst 之后去向(converge / ten-reveal)
- 揭示顺序在前端排序:`RARITY_RANK` 升序、同稀有度保持原序;`revealed` 计数驱动,effect 按下一张稀有度定时不等长停顿
- 卡背 `.ten-card-back`:精灵球 + 斜纹 + 烫金边,纯 CSS,无图片资源
- UR 压轴三件套全部 transform/opacity 实现,`prefers-reduced-motion` 下自动停(沿用全局规则)
