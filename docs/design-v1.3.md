## 二、开屏冒险动画(Splash)

仅首次访问播放(localStorage `pdx_adventure=1`),随时可"跳过";老访客直接进图鉴。

时间轴(全部 CSS 动画 + 少量状态机):
1. 0.0s 深夜蓝全屏
2. 0.3s 精灵球(纯 CSS:红白半球+中钮)从顶部落下,落地回弹
3. 1.2s 左右摇晃两下(加速)
4. 2.0s 白光径向炸开
5. 2.3s 精灵球淡出,「宝可梦图鉴 AI」标题上浮,副标题「查证 · 收集 · 对战——你的 AI 宝可梦冒险」
6. 主按钮「▶ 开启我的宝可梦冒险」脉动;点击 → 白光过渡 → 进图鉴,写 localStorage
7. 右下角常驻「跳过 »

## 三、卡面系统(完整集换式卡框,全站复用组件)

结构:属性色渐变卡头(属性徽章+官方中文名+HP 数字)→ 官方立绘大图 → 稀有度绶带 → 卡脚(数量/编号)。

稀有度卡框:
- C:白净卡框 + 灰绶带
- R:蓝色微光边框
- UR:金色流动渐变边框(keyframes 旋转)+ hover 卡面光泽扫过(holo sweep)

立绘:`https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master (已迁移,原 raw.githubusercontent)/master/sprites/pokemon/other/official-artwork/{id}.png`
——由 id 直接推导,**无需改数据库**;像素图仅保留在图鉴详情的小尺寸场景(若有)。

## 四、开包仪式感(状态机驱动的纯 CSS 动画)

点击购买 → fetch 与动画并行,两者都完成才揭晓:

```
idle → pack-in(卡包浮现) → shake ×2(加速摇晃 1.4s)
     → burst(白光 0.4s) → cardback(卡背悬浮)
     → flip(3D 翻转 0.7s) → revealed(卡面定格 + 稀有度特效)
```

- UR:金光粒子爆发(CSS 粒子)+ 全屏微光;R:蓝光涟漪
- 连续抽:点击「跳过动画」直接到 revealed
- 失败(币不足等):卡包不开,提示气泡

## 五、对战竞技场(动画编排器)

核心改造:**服务器返回的事件数组按顺序逐个播放**(现在是瞬间倾倒)。

- 场地:双方脚下椭圆站台 + 属性色柔和渐变背景
- 待机:精灵上下浮动(idle float)
- 出招:攻击方向对手突进再弹回(lunge);受击方抖动+红闪;伤害数字头顶飘出上浮消散
- 克制弹出:「效果绝佳!」大字弹出
- HP 条:双层——红色实条即时 + 白色 ghost 条延迟跟落(格斗游戏手法)
- KO:倒下淡出;胜利:横幅弹出 + CSS 彩带;战败:暗幕缓落
- 推演模式:AI 理由行带 🤖 标识,行动与理由成对播放
- 编排器:约 100 行的时序播放器(setTimeout 队列),动作期间输入锁定(复用 busy)
