## 每轮评审抓出的关键问题(评审的价值证明)

- r0→r1:对战准备页整页浅色断裂(根因:`useTheme` 只挂在单个视图,其他视图回退浅色)——主题必须在 App 根部应用
- r1→r2:「图鉴主页大卡原封未动、开包揭晓无仪式、爆开帧逐像素等于没做」三条核心承诺两条落空
- r2→r3:揭晓三帧无差异——真凶有二:①放射光被包体 `overflow:hidden` 裁掉;②「跳过动画」直接跳过 burst 阶段(动画从未挂载);另揪出**替补 HP 超上限(168/166)**数据 bug
- 评审方法本身:截图时机骗人(截图延迟 ~1s 吃掉 500ms 动画窗口),最终用 Web Animations API 冻结动画抓帧自证——「验证不了的效果等于没有」
